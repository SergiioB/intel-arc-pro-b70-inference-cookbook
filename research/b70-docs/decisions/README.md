# decisions/

ADRs — why a route was selected, what alternatives were rejected, and what
would trigger a re-review. Numbered `adr-NNNN-<slug>.md`, append-only; a
superseded ADR is marked, never deleted.

Key ADRs referenced by the contract: ADR-0008 (dual-B70 independent stacks
default), ADR-0009 (Xe2 megakernel and persistent-fusion policy).

Index: `docs/indexes/decision-index.md` (generated). Current open questions
live in `registry/research-ledger.json`, not here.
