# tools/ and scripts/

1. `python3 tools/research.py next` selects one actionable research question; `price` evaluates explicit-unit bounds; `source` retains primary-source bytes and provenance.
2. `run --plan PATH`, `assess --run PATH`, `record --run PATH` execute bounded paired experiments, preserve raw failures and register scoped outcomes. Commands and schemas: `docs/governance/agent-operating-system.md`.
3. `render`, `check`, `coverage` keep existing program/ledger/model/campaign authorities and their generated views consistent.
4. `tools/situation.py compile` remains for a named ops/bench/diagnose/publish/site working set. It does not choose autonomous research priorities. Its `close` checks existing campaign evidence linkage.

`tools/build-indexes.py` regenerates document indexes. `tools/check-frontmatter.py`
and `tools/check-links.py` check documentation conventions. `scripts/` contains
engine-specific benchmark/operation adapters; new hardware scripts start in
`scripts/tmp/` and need controlled-run evidence before promotion.
One-shot migration scripts are not permanent execution paths.
