### What RL-195 does and does not establish

`xtq_beat_sweep_20261013.py:38-47` defines C as `{sigma_reg:0.025, cb_fold:true, gscale:"search"}` and F as C plus one `sv_refine` pass. The three held-out L02 ratios are credible **partial weighted-error observations**, not chat-only KL or guarantees about all layers.

There is an evidence-label inconsistency to preserve: retained README:5 says held-out Gram is half the calibration rows. Actual input writer `xtq_beat_inputs_20261013.py:22-23,38-48,57-58` writes **H_cal_half0/half1 separately** and **H_ho from evaluation windows**, including full chat prompt/context, not only response positions. Sweep:146-161 fits full H_cal and scores H_ho; halves are used for sigma CV:167-174. Therefore the reported L02 H_ho gain is a **mixed wiki/full-chat-context BF16-propagated Gram**, not clean chat-response-only evidence. It is not fitted directly, but repeatedly selecting variants using it would consume the held-out set. Keep the historical two slices as a screen; freeze the next recipe from source evidence, use independent calibration-only CV for tuning, and reserve fresh conversations/wiki documents for confirmation.

## 4. Most likely causes, ranked

1. **[INFERENCE] Quantizer recipe mismatch: RMS-only global scale plus weaker/default-history-dependent damping.** This has the strongest positive mechanism evidence: C_exl3 reduces Q2's held-out tensor error from1.034–1.040 to0.991–0.998 on the same three L02 tensors. It changes error distribution rather than storage/bitrate. Chat's gated/recurrent paths can amplify different channel errors even when wiki's aggregate KL improves. No isolated scale/damp experiment or prefix C KL result exists, so do not claim it already closes the8.51% chat loss.
2. **[INFERENCE] Calibration token and execution non-parity, despite matching nominal default mix.** The HF approximation is not merely unknown: the code/config imply skipped BOS248044 versus upstream native BOS, possible EOS/special-string differences, and calibration forwards use BF16 source a/b whereas the exported model keeps plain FP16 a/b. Native packed propagation and Transformers dense propagation differ. These can bias measured H toward the wrong effective inputs. Exact native calibration rows and runtime Gram comparison are needed to size the effect. Generic “need512k instead of32k” is historical RL-191 advice, already implemented for Q2.
3. **[INFERENCE] Objective/domain mismatch and correlated error accumulation.** Both default mixes are prose/code/random-heavy with no explicit chat-template curriculum; raw XᵀX weights every calibration token rather than response loss or downstream logit sensitivity. Reusing signs across same-shaped tensors and optimizing fitted tensor error can favor wiki while harming a small structured chat slice. RL-191's fitted-error/output-KL contradiction directly supports the proxy limitation. However, a shared corpus limitation alone cannot explain upstream's advantage; recipe, tokenization and arithmetic interactions distinguish the two pipelines.

Lower-ranked or excluded: plain K allocation and head bits match; the MTP/vision branches are outside this teacher-forced text KL path; Hadamard128 and LDLQ16/128 reverse sweep match; no evidence supports blaming storage layout or changing mcg. Narrow slices can exaggerate a domain tradeoff—only two conversations are represented—so neither wiki improvement nor chat failure establishes general task quality.

### Why lower Hessian error is not lower KL

For one linear, fitted error is `tr(ΔW H_cal ΔWᵀ)`. At the final logits, local second-order KL depends on the downstream Jacobian, softmax curvature, activation distribution and **cross-layer error interactions**. A sum of fitted tensor errors omits these terms; it is neither an additive upper bound on KL nor a valid substitute for an output gate. Normalization/nonlinearities, recurrent state and gated FFNs make the domain dependence plausible. Prefix and full-depth results can differ in direction; the cheap prefix can reject a candidate but cannot establish a full-depth win.
