Changed parameter
- nt_of(3, MR): NT = number of 16-column trellis tiles per vector thread;
  MR is 1, 2, 4 or 8 rows. P2 gives K3 explicit entries, independently overridable
  as EXL3_K3_NT_MR1/2/4/8 through EXL3_FLAGS. Defaults = [8,4,4,4].
- This is NOT a native INT3 DPAS path: trellis codes decode to fp16; vector GEMV
  handles M<=2, existing fp16 DPAS handles M=3..128, reconstructed fp16 GEMM
  handles M>128. Do not ascribe extra XMX TOPS to three-bit storage.
- Existing DPAS geometry remains N=16, SD=8, K_instr=16 (fp16), repeat rows 8;
  MB=8/16/24/32/40/48/64 groups those row repeats. No DPAS tile changes here.

Legality and paper resource budget
- Geo<3>: G=8, TP=32/G=4, GV=32, W=24 uint32 words per tile.
  NP=NT/4; ACC=MR*NP*2*32=16*MR*NT elements.
- Require NT in {4,8}. Both divide every real N/16 and do not cross a 128-column
  shard boundary. NT=2 is illegal; NT=16 crosses shard assumptions and is excluded.
- Named live arrays (not compiler allocation): acc fp32 + hacc fp16 = 96*MR*NT B;
  words+prev = 192*NT B; xr = 32*MR B. Subtotal at MR1 NT8 = 2,336 B;
  MR8 NT4 = 4,096 B; MR8 NT8 = 7,936 B. The step copies dw/pw add up to 768 B
  before compiler reuse; decoded values/indices, reduction vectors and address
  temporaries are additional. This is a lower-bound inventory, not spill proof.
- GEMV adds no SLM. Preserve upstream work-group size, split-K settings and GRF
  properties for the first screen. Do not blindly add subgroup attributes to an
  ESIMD functor (ESIMD differs from implicit-SIMD subgroup kernels).
- Later compiler/IGC register reports and profiler scratch traffic must establish
  occupancy under the 64 KiB/XVE budget. Reject spilling variants before timing.

Sweep ownership and order
1. Architect accepts D3 option; orchestrator assigns an isolated build/test window.
   Source oneAPI; discover storage live; use dedicated build/output dirs and save
   source SHA, ordered patch hashes, flags, compiler versions and complete logs.
2. Build repaired default [8,4,4,4] and one-coordinate variants: MR1=4,
   MR2=8, MR4=8, MR8=8. Five initial candidates, not a 16-build blind sweep.
   Only combine independently winning changes after correctness; max 16 legal
   combinations total. Default serving uses MR1/2; MR4/8 use P3 raw diagnostics.
3. Run P3 for every proposed finalist; first screen one module per each of the
   seven real width-48 families, then ALL 400 real modules for promotion. No
   substitution of 4bpw payload. A screen subset is never full correctness PASS.
4. Reconstruction reference is exl3_ops.sycl:545 (base numbering), K3/cb2.
   Compare every decoded weight with Triton at zero tolerance, then forced raw
   one-hot GEMV/DPAS at zero tolerance. Dense output comparisons use the frozen
   P3 row-relative L2 and absolute/RMS limits; no tolerance adjustment on failure.
5. Run n=3 screens, fresh n=5 finalist measurements, same-shape warmup discarded.
   Time default public op under graph replay, not eager dispatch: M=1,2,4,8,
   16,32,64,128; report per-shape median/max/range and replay launch count.
   MR4/8 forced-vector timings are diagnostic only, not serving-path wins.
6. Isolated gate: >=5% weighted latency reduction against repaired default at
   M=1/2 (weights from the 400-module census), no >5% regression in any default
   serving cell; reject a noise-sized gain. Then P4 end-to-end gates decide
   adoption. If default wins, retain defaults and explicitly record no tuning win.

  script. No measurements are performed by this authoring task.
- Require approved D3 record, live ownership and empty-card gates, projected
  scratch+weight+graph reserve, >=2 GiB post-load free, exact library hash, trace
  confirming K3 dispatch under replay and no unexpected host synchronization.
- One controlling process, one client; log progress before/after every cell.
  Per cell deadline 120 s after JIT warmup; first-shape JIT deadline 300 s;
  screen window deadline 30 min. Timeout/OOM/unsupported dispatch/nonfinite/
  incomplete evidence = STOP, no fallback score and no automatic retry.
- Save all timings and exclusions. No global scratch cache, tolerance loosening,
