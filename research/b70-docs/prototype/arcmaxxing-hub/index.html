Generate Host Launch Script

Select your model, target engine, and context budget for a turnkey verified configuration.

Context Window 65,536 tokens

launch_recipe.sh 
# 1. Activate Intel oneAPI Environment
source /opt/intel/oneapi/setvars.sh --force >/dev/null 2>&1

# 2. Enforce 150W Arc Pro B70 Power Cap
sudo bash -c 'echo 150000000 > $(find /sys/devices -name power1_cap | grep xe)'

# 3. Launch llama.cpp SYCL Server with Safe KV Quantization
./build-sycl/bin/llama-server \
  -m ./models/Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf \
  -ngl 99 \
  -ncmoe 0 \
  -fa on \
  -ctk q8_0 \
  -ctv q4_1 \
  -c 65536 \
  -t 8 \
  --no-mmap \
  --host 0.0.0.0 \
  --port 8080
Key Invariants Enforced:
• -ctk q8_0 -ctv q4_1: Preserves attention precision without Q4_0 K perplexity drop.
• -fa on: Hardware FlashAttention enabled for Arc XMX matrix acceleration.
• --no-mmap: Ensures clean VRAM allocation without kernel page-fault thrashing.

Naming Analysis: IntelMaxxing vs ArcMaxxing

Detailed review of domain risk, Intel Corporation trademark guidelines, and proposed brand strategy.

intelmaxxing.com Risk

Intel® is an aggressively enforced trademark worldwide. Domain names containing "Intel" are subject to UDRP (Uniform Domain-Name Dispute-Resolution Policy) forfeiture, particularly if monetized, carrying affiliate links, or hosting benchmarks that imply official endorsement.

Recommendation: Park domain as 301 redirect to neutral hub; do not make it the primary commercial corporate entity.
ArcMaxxing / XeMaxxing

ArcMaxxing or XeMaxxing creates direct product resonance with Intel Arc GPUs and Xe2 architecture while avoiding verbatim trademark collision in corporate titles.
