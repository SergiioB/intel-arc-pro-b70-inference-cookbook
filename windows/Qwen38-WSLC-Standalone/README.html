Qwen3.8-27B on Microsoft WSLC

This guide installs the reproducible Intel Arc Pro B70 WSLC configuration.

Requirements

  • Windows 11 with Microsoft WSLC installed
  • Intel Arc Pro B70 and a current Windows driver
  • At least 22 GiB free for the model, plus image space
  • An ordinary PowerShell window; administrator mode is normally unnecessary

Get a Hugging Face token

The public model can download without authentication, but a token normally provides higher rate limits. Hugging Face calls it an access token.

  1. Sign in at huggingface.co.
  2. Open Settings → Access Tokens.
  3. Create a new Read token. Write access is unnecessary.
  4. Copy the value beginning with hf_.

Current PowerShell window only:

$env:HF_TOKEN = "hf_your_read_token_here"

Save permanently for your Windows user:

[Environment]::SetEnvironmentVariable(
    "HF_TOKEN",
    "hf_your_read_token_here",
    "User"
)

Open a new PowerShell window after saving permanently, or also set $env:HF_TOKEN in the current one. Verify without displaying the secret:

if ($env:HF_TOKEN) { "HF_TOKEN is set" } else { "HF_TOKEN is not set" }

Security: Treat the token like a password. Never include it in screenshots, bug reports, Git commits or chat. Revoke it from Hugging Face if exposed.

Complete installation

Extract the complete ZIP, then open PowerShell in the extracted root folder:

Set-ExecutionPolicy -Scope Process Bypass
.\Setup-Qwen38-WSLC.ps1

The installer builds the pinned image, verifies B70 compute, reuses or downloads the approximately 18.2 GiB model, and starts the server. Partial downloads are resumable.

For a manual model copy, place the complete repository contents directly in:

.\models\Qwen3.8-27B-GPTQ-Int4

Main controls

.\Start-Qwen38.ps1 -MtpTokens 4 -MaxModelLength 100000 -GpuMemoryUtilization 0.75 -KvCacheMemoryGiB 4.25 -KvCacheDtype fp8
.\Stop-Qwen38.ps1

Other controls

.\Test-CookbookDecode.ps1
  • Endpoint: http://127.0.0.1:8000/v1
  • Model: qwen38
  • Automatic tool choice enabled with the qwen3_coder parser; vision disabled
  • MTP4, 100K context, FP8 KV cache, explicit 4.25 GiB cache
