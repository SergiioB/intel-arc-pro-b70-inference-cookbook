Qwen3.8-27B on Docker Desktop

Windows container devised and tested by Ian Hudson – aitesthive.com

This guide installs the proven Intel Arc Pro B70 Docker Desktop configuration.

Requirements

  • Windows 11 and Docker Desktop using its Linux/WSL2 engine
  • Intel Arc Pro B70 and a current Windows driver
  • At least 22 GiB free for the model, plus image space
  • An ordinary PowerShell window; administrator mode is normally unnecessary

Step 1: Install Docker Desktop manually

Download Docker Desktop for Windows from the official Docker installation page. Install it, select the Linux/WSL 2 engine, start Docker Desktop and wait until the engine reports that it is running.

In a new ordinary PowerShell window, check:

docker context use desktop-linux
docker info

If docker info reports permission denied, an administrator can run:

net localgroup docker-users "$env:USERNAME" /add

Sign out of Windows and sign back in—or reboot—after changing group membership. Then start Docker Desktop and run docker info again.

Get a Hugging Face token

The public model can download without authentication, but a token normally provides higher rate limits. Hugging Face calls it an access token.

  1. Sign in at huggingface.co.
  2. Open Settings → Access Tokens.
  3. Create a new Read token. Write access is unnecessary.
  4. Copy the value beginning with hf_.

Current PowerShell window only:

$env:HF_TOKEN = "hf_your_read_token_here"

Save permanently for your Windows user:

[Environment]::SetEnvironmentVariable(
    "HF_TOKEN",
    "hf_your_read_token_here",
    "User"
)

Open a new PowerShell window after saving permanently, or also set $env:HF_TOKEN in the current one. Verify without displaying the secret:

if ($env:HF_TOKEN) { "HF_TOKEN is set" } else { "HF_TOKEN is not set" }

Security: Treat the token like a password. Never include it in screenshots, bug reports, Git commits or chat. Revoke it from Hugging Face if exposed.

Complete installation

Extract the complete ZIP, start Docker Desktop, then open PowerShell in the extracted root folder:

Set-ExecutionPolicy -Scope Process Bypass
.\Setup-Qwen38-Docker.ps1

The installer builds the pinned image, verifies B70 compute through /dev/dxg, reuses or downloads the approximately 18.2 GiB model, and starts the server. Privileged mode is not required.

For a manual model copy, place the complete repository contents directly in:

.\models\Qwen3.8-27B-GPTQ-Int4

Main controls

.\Start-Qwen38-Docker.ps1
.\Stop-Qwen38-Docker.ps1

Other controls

.\Build-Qwen38Image-Docker.ps1
.\Test-CookbookDecode.ps1

Keep the stopped container rather than removing it if you want to preserve its compiled graph cache.
