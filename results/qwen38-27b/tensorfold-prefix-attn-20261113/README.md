# TensorFold prefix attention kernel on the B70 — 2026-11-13

Evidence for the "Prefix attention kernel" section of
[`docs/qwen38-27b/TENSORFOLD-B70.md`](../../../docs/qwen38-27b/TENSORFOLD-B70.md). Status: screen, one host.

## Shape

- Intel Arc Pro B70 32 GB. Card 1 at a 230 W cap for every run except `gpu0-*` (card 0, 180 W). One server on the
  measured card. `gpu0-pref256` ran while card 1 served a quality battery.
- TensorFold `SergiioB/TensorFold` tag `b70-attn-prefix-20261113` (commit `4f7042f2d7ce35e5376b82db1120eedaccff164b`),
  which is upstream PR #2595's head `078cac06b` plus [`patches/attn-prefix-4f7042f2d-on-078cac06b.patch`](patches/attn-prefix-4f7042f2d-on-078cac06b.patch),
  plus the local ocloc build fix described on the family page. Zig 0.17.0, ocloc 26.05.
- Model `TensorFold/Qwen3.8-27B-MLX-4bit` @ `22d8d538`, drafter `z-lab/Qwen3.8-27B-DFlash2`.
- `--parallel 1 --context 139264 --prompt-cache-gib 0 --no-thinking`, greedy, 512 output tokens, one stream, cold
  prompt on every request. The 250K cell uses `--context 262144`.
- Prompts: the frozen set of [`tensorfold-depth-20261108`](../tensorfold-depth-20261108/) (sha256 `74afe579…`). The
  249,784-token prompt is the same source text extended; it is not vendored (sha256 of its file in
  `kv8-pref256-262k/env.txt`).
- Decode tok/s is the streamed rate after the first token. Energy is the card counter, sampled around the request.

Runs: `control-samebin` (switch unset), `pref256-full` (0–32K, 2 repeats), `pref256-128k` and `pref256-128k-x3`
(131K, 4 repeats in all), `reorder-pref512` (512-key chunks), `gpu0-control` / `gpu0-pref256` (second card),
`premin-default` / `premin-pref256` / `premin-pref256-128k` (position floor), `kv8-control` / `kv8-pref256` /
`kv8-pref256-128k` / `kv8-pref256-262k` (int8 K/V), `tag-pref256` (tagged build, bf16).

## Boundaries

- The switch changes the answer text against the switch-unset build on 4 of 6 depth cells and 67 of 329 battery
  items. It is deterministic and equal with and without drafting. It is not in upstream TensorFold.
- The battery ran on the first form of the kernel (no position floor, bf16 K/V). `"draft": false` covered 275 of
  its 329 items.
- int8 cells have one repeat and no control at 131K and 250K. `premin-pref256-128k` was cut short by a session
  restart after three requests.
- Not run: retrieval at depth, prompt-cache resumes, concurrent streams, sampled decoding.
- The scripts name lab paths through `$TF`, `$RUN`, `$BENCH` and `$PROMPTS`; `tf_depth_run.sh` and `depth_bench.py`
  are in the 2026-11-08 folder.
